# Machine-Learning-Final-Project---Predicting-Used-Car-Prices-
Problem: The used car market is complex and opaque. Prices are influenced by many factors, making it difficult for buyers and sellers to determine fair market value. 
Objective: To build a machine learning model that accurately predicts used car prices based on vehicle attributes.
The dataset, 'vehicles', used was pulled from Craigslist. Link to dataset: https://drive.google.com/file/d/1qKdMN9-lVXt2ZHpt35wrrziJqQ6RW5eg/view?usp=sharing
